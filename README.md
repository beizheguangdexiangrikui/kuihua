## 这是什么

它不是又一个套壳聊天框，而是把「模型接入 → 提示词编排 → 工具调用 → 结果验证」做成一条完整流水线：

- **多模型直连**：DeepSeek / OpenAI / Claude / Gemini / 通义 / Kimi / 智谱 / 硅基流动 / OpenRouter / 小米 MiMo 等 27 家，一个界面切换
- **提示词模板引擎**：8 份内置人格模板，一键作为 system 注入，可编辑、可还原、可导入导出
- **本地工具箱**：阅读、写入、编辑、预览、终端、目录、截图、联网搜索、抓网页——模型不只会说，还能动手
- **插件生态**：321 个插件入口，MCP 服务器一键安装/启用/卸载，装完即可被模型调用
- **指令遵循度检测**：四探针自动测试模板生效情况，输出百分比、评级与范围明细
- **省 token 模式**：长会话只发最近若干条、模板只注入一次，帮你在长对话里省钱
- **桌面体验**：系统托盘、黑白主题、美化皮肤、实时 API 余额、拖拽附件、应用内更新

## 🛡️ Claude 防封

先把话说在前面：**没有任何客户端能保证「不被封」**。封不封由 Anthropic 服务端判定，看的是出口 IP、环境画像、请求节奏、支付方式这些**服务端能看到的东西**。应用能做的，是把「本可避免却没避免」的信号一条条消掉，显著降低被标记的概率。

### 什么情况会被封（2026 最新）

| # | 封号原因 | 风控怎么判 |
|---|---|---|
| ① | **用高风险地区的 IP 直连** | Anthropic 拿请求 IP 查 ASN 归属（IPinfo / MaxMind）：**数据中心 IP、共享 VPN 出口池**（Nord / Surfshark 这类）直接标高风险；中国大陆等地区本身不在其服务范围 |
| ② | **环境画像互相矛盾** ★ | **出口地区 · 系统时区 · 系统语言**三者不一致本身就是信号：从美国 IP 出去、系统时区却是 `Asia/Shanghai`、语言还是 `zh-CN` —— 一眼看出在伪装地区 |
| ③ | **IP 前后不一致** | 注册 IP ≠ 充值 IP ≠ 日常使用 IP → 判定账号转卖 |
| ④ | **新号 24–72 小时猛用** | 刚注册就高频调用、大 token 消耗 → 进人工审核（KYC） |
| ⑤ | **多 IP / 多设备同时活跃** | 「拼车号」的典型特征，查出来一锅端 |
| ⑥ | **支付环节出问题** | 虚拟卡 BIN（Wildcard 这类）批量被拒；付款时用数据中心 IP 也会被风控 |

### 这个应用替你做了什么

应用「设置」页里有 **🛡️ Claude 防封中心**。点 **「⚡ 一键优化」** 就能把应用能自动做的全部做掉；点「防封体检」则只诊断、不改动。

| 我们做的 | 解决上面哪条 |
|---|---|
| **⚡ 一键优化** —— 下面凡是可以自动做的（开节流、加抖动、对齐语言），一次点完全部做掉 | ②④⑤ |
| **请求指纹正常化** —— 以前发给 Anthropic 的请求**连 User-Agent 都没有**（裸请求在所有正经客户端里都反常），现在带稳定一致的中性 UA，且只发必要的头 | 泛指异常特征 |
| **出口 IP 与线路类型自检** —— 查你实际从哪个 IP / 地区 / 线路出去，读 IP 情报的托管/代理标志，判断是**住宅线路**、**数据中心 IP** 还是**共享 VPN 出口池** | ① |
| **环境一致性检查** —— 把「出口地区 · 系统时区 · 系统语言」放一起比对，矛盾就报警；**请求语言可一键对齐出口地区** | ② |
| **请求节流 + 随机抖动** —— 同一服务商的请求串行发送、每次至少间隔几秒，并加 0–2 秒随机抖动（机器般精确的等间隔反而像脚本，人是有快有慢的） | ④⑤ |
| **熔断保护** —— 某个服务商被连续限流/拒绝（429/403/529）三次，自动冷却 5 分钟，不再继续猛撞 | ④⑤ |
| **按服务端额度自适应调速** —— 读官方响应头的 `anthropic-ratelimit-*`：体检里能看到「这个 key 本轮还剩多少」，**剩余低于 15% 时自动拉长发送间隔**，避免撞上 429 | ④⑤ |
| **严格遵守 `retry-after`** —— 被限流时服务端说等几秒就等几秒，不自己拍固定退避；并区分「花超月度上限」（重试无用，要等下月）与普通限流 | ④⑤ |
| **代理支持** —— 全局代理 + 按服务商单独配，让 Claude 流量固定走一条线路；自检走你配的代理，测的就是真实出口 | ①③ |
| **密钥卫生** —— API 密钥只存本机（能用系统密钥库时自动加密），不进日志、不随导出带走 | 泛指 |

### 这些是应用做不到的（面板里也会明确列出来）

| 做不到的 | 为什么 |
|---|---|
| **换掉脏的出口 IP** | 公开资料一致强调：所有本地伪装的**前提是出口 IP 本身干净**。节点 IP 已进黑名单的话，本地怎么改都没用 |
| **改你的系统时区 / 语言** | 应用改不了 Windows 设置，得你自己去改 |
| **TLS 传输层指纹（JA4）** | Node 的 TLS 握手特征与 Chrome 不同；要完全模拟得换传输层实现（uTLS 这类），本版没做 |
| **支付方式 / 共用 key / 内容合规** | 都在应用控制范围之外 |

### 还有几条只能靠你自己

- **别多人共用同一个 key**（这是封得最快的一种）
- **新号头三天少量使用**：每天 5–10 次对话，别开批处理
- **用真实卡，不用虚拟卡**
- **长期固定同一条线路**：不要今天美国、明天日本地跳

> 所以：**「彻底防封」这种东西不存在**，谁说有谁在骗你。这个应用做的是把「本地环境」这一侧能做的做到位。做到上面这些，被封的概率会低很多——但依然不是零。这点我们不含糊。

## 常见问题

**Q：必须买吗？**
不用。下载与绝大部分功能都免费；只有内置模板、启用模板开关、指令检测三项需要应用内 20 元解锁。自定义模板可以免费用。

**Q：密钥会上传到你的服务器吗？**
不会。密钥只存本机（能用系统密钥库时自动加密），请求直接从你的机器发往模型服务商。

**Q：换电脑要重新买吗？**
激活码绑定设备。换电脑需要在应用里拿到新设备码，联系作者换发激活码。

**Q：更新会丢配置吗？**
不会。对话记录、插件、API 配置都在 `%APPDATA%\葵花宝典`，换 exe 不动它们。
