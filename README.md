# 葵花宝典 · 多模型 AI 效率工作站

> **一个桌面端 AI 工作站**：接入 22 家大模型服务商，自定义系统提示一键注入，内置本地工具与插件生态，让模型真的能动手帮你干活。

**官网**：https://lyt19202285014-afk.github.io/kuihua/

## 这是什么

葵花宝典（Kuihua Baodian）是一款 Windows 桌面端 **多模型 AI 效率工作站**。

它不是又一个套壳聊天框，而是把「模型接入 → 提示词编排 → 工具调用 → 结果验证」做成一条完整流水线：

- **多模型直连**：DeepSeek / OpenAI / Claude / Gemini / 通义 / Kimi / 智谱 / 硅基流动 / OpenRouter / 小米 MiMo 等 22 家，一个界面切换
- **提示词模板引擎**：7 份内置人格模板（通用助手 / 编码 / 写作 / 角色 / 分析…），一键作为 system 注入，可编辑、可还原、可导入导出
- **本地工具箱**：阅读、写入、编辑、预览、终端、目录、截图、联网搜索、抓网页——模型不只会说，还能动手
- **插件生态**：127 个插件入口，MCP 服务器一键安装/启用/卸载，装完即可被模型调用
- **指令遵循度检测**：四探针自动测试模板生效情况，输出百分比、评级与范围明细
- **桌面体验**：系统托盘、黑白主题、6 款美化皮肤、实时 API 余额、检查更新

## 核心能力

### 1. 多模型接入

| 协议 | 服务商 |
|---|---|
| OpenAI 兼容 | DeepSeek、通义千问、Kimi、智谱 GLM、硅基流动、OpenRouter、火山方舟、MiniMax、百川、阶跃星辰、腾讯混元、讯飞星火、Ollama、llama.cpp、自定义端点 |
| Claude 协议 | Anthropic Claude、Claude 中转、小米 MiMo（Claude 协议） |
| Gemini 协议 | Google Gemini |

- 密钥仅存本机（系统密钥库加密）
- 一键测连通、查余额、拉取官方模型清单
- 支持 HTTP 代理、自定义 baseUrl

### 2. 提示词模板引擎

把 system prompt 当成可管理的「人格配置」：

- 7 份内置模板，覆盖通用、编码、写作、角色扮演、安全分析等场景
- 支持新建、编辑、复制、还原、导入导出
- 右栏实时预览注入内容与字数
- **启用 / 停用一键切换**，停用即回归普通助手

### 3. 本地工具箱（10 个）

模型可以真的动手：

| 工具 | 作用 |
|---|---|
| `read_file` | 读取本机文件 |
| `write_file` | 写入文件 |
| `edit_file` | 精确替换修改 |
| `preview_file` | 预览文本/图片 |
| `run_command` | 执行 PowerShell |
| `list_dir` | 列目录 |
| `open_app` | 打开应用/网址 |
| `screenshot` | 屏幕截图 |
| `web_search` | 联网搜索（按时间过滤，优先最新） |
| `fetch_url` | 抓取网页转纯文本 |

所有工具走权限闸门：只读工具直接放行，写操作可配置确认策略。

### 4. 插件与 MCP

- **127 个插件条目** / 9 大分类（MCP 服务器、宿主、Agent 平台、本地前端、ComfyUI、Blender、Unity、浏览器扩展、工具运行时）
- 36 个 npm 插件**应用内一键安装**，装完自动启用
- MCP 服务器装好后，工具直接暴露给模型调用
- 支持卸下（停用）与卸载（删除）

### 5. 指令遵循度检测

四路探针（口令回执、免责过滤、冗余说教、执行力）自动测试，输出：

- **生效百分比**（0-100%）
- **评级**：完全生效 / 大部生效 / 部分生效 / 轻微生效 / 未生效
- **生效范围明细**，报告可导出 Markdown

### 6. 桌面体验

- 系统托盘常驻，关窗最小化到托盘
- 深色 / 浅色 / 跟随系统主题
- 6 款美化皮肤（极光紫蓝 / 森林绿 / 日落橙 / 玫瑰粉 / 极简单色）
- 对话页实时 API 余额
- 全局快捷键
- 检查更新（作者发布新版本后自动提示）
- 截图与文件附件
- 流式对话、中断、重生成、导出
