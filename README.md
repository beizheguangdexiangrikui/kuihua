## 这是什么

它不是又一个套壳聊天框，而是把「模型接入 → 提示词编排 → 工具调用 → 结果验证」做成一条完整流水线：

- **多模型直连**：DeepSeek / OpenAI / Claude / Gemini / 通义 / Kimi / 智谱 / 硅基流动 / OpenRouter / 小米 MiMo 等 27 家，一个界面切换
- **提示词模板引擎**：8 份内置模板，一键作为 system 注入，可编辑、可还原、可导入导出
- **本地工具箱**：阅读、写入、编辑、预览、终端、目录、截图、联网搜索、抓网页——模型不只会说，还能动手
- **插件生态**：321 个插件入口，MCP 服务器一键安装/启用/卸载，装完即可被模型调用
- **指令遵循度检测**：四探针自动测试模板生效情况，输出百分比、评级与范围明细
- **省 token 模式**：长会话只发最近若干条、模板只注入一次，帮你在长对话里省钱
- **网络环境自检**：检查出口线路与环境配置，给出可执行建议（见下文）
- **桌面体验**：系统托盘、黑白主题、美化皮肤、实时 API 余额、拖拽附件、应用内更新

### 2. 提示词模板引擎

把 system prompt 当成可管理的「人格配置」：

- 8 份内置模板，覆盖通用、编码、写作、角色扮演、安全分析等场景

| 工具 | 作用 |

- **321 个插件条目** / 11 大分类（MCP 服务器、宿主、Agent 平台、本地前端、ComfyUI、Blender、Unity、浏览器扩展、工具运行时）

- MCP 服务器装好后，工具直接暴露给模型调用
- 支持停用与卸载

### 5. 指令遵循度检测

四路探针（口令回执、免责过滤、冗余说教、执行力）自动测试，输出：

- **生效百分比**（0-100%）

长会话里每次请求都要重发整段历史，越聊越贵。开这个模式后：

- 可设文本附件截断字数

- 会话变长时输入区会主动提醒，并给一键「新开会话」

- 深色 / 浅色 / 跟随系统主题，多款美化皮肤与动态壁纸

## 🌐 网络环境自检（设置页）

**先说清楚：任何客户端都无法保证你的账号「一定可用」**——是否可用由服务商的服务器判定。这个面板做的事是：把你这边**容易踩的坑**提前查出来，让你少遇到莫名其妙的请求失败、限流或账号受限。

### 常见现象与原因

| # | 你会遇到的现象 | 常见原因 |
|---|---|---|
| ① | 请求频繁失败、超时 | 出口网络不被服务商支持：机房 IP、共享 VPN 出口段，或该地区本身不在其服务范围内 |
| ② | 环境"看着不自洽" | **出口地区 · 系统时区 · 系统语言**三者不一致（例如从美国出口出去，系统时区却是 `Asia/Shanghai`、语言还是 `zh-CN`）。服务商会把这种不一致当作异常信号 |
| ③ | 频繁要求重新验证 | 注册、充值、日常使用走了不同地区的出口 |
| ④ | 新账号很快被限制 | 刚注册就高频调用、大 token 消耗 |
| ⑤ | 多人同时用会被限流 | 同一个 key 被多个 IP / 多台设备同时使用 |
| ⑥ | 订阅 / 充值失败 | 支付方式或付款时的网络出口被判定为异常 |

### 应用提供的自检与一键优化

「设置」页 → **🌐 环境自检**。点 **「⚡ 一键优化」** 把可自动处理的项目一次做完；点「体检」则只诊断、不改动。

| 功能 | 作用 |
|---|---|
| **⚡ 一键优化** | 下面可自动处理的项目一次全部完成 |
| **出口网络检测** | 查你实际从哪个 IP / 地区 / 线路出去，读 IP 情报的托管标志，区分**住宅线路**、**机房 IP**、**代理出口**与**移动网络** |
| **环境一致性检查** | 把「出口地区 · 系统时区 · 系统语言」放一起比对；不一致就提示，**请求语言可一键对齐出口地区** |
| **请求节奏控制** | 同一服务商的请求串行发送、每次至少间隔几秒，并加 0–2 秒随机抖动，避免短时间密集请求 |
| **限额感知与自适应** | 读取服务端返回的额度信息，显示「本轮还剩多少」；剩余不多时**自动放慢发送间隔**，避免触发限流 |
| **严格遵守服务端要求** | 被限流时服务端会告知需要等待多久，应用就按它说的等；并区分「本轮额度用完」与「账户额度用完」两种情况给出不同提示 |
| **失败熔断** | 某服务商连续返回限流类错误时自动暂停一段时间，不再连续重试 |
| **代理支持** | 全局代理 + 按服务商单独配置，让特定服务商的流量固定走一条线路 |
| **密钥卫生** | API 密钥只存本机、不进日志、不随导出带走 |

### 自检做不到的（面板里也会列出来）

| 做不到的 | 为什么 |
|---|---|
| **更换你的出口线路** | 应用只能告诉你当前线路的类型；换线路要你自己准备 |
| **修改系统时区 / 语言** | 应用改不了 Windows 设置，需要你自己调整 |
| **底层传输特征** | 应用的网络库与浏览器的握手特征不同，本版未做模拟 |
| **支付方式 / 密钥共用 / 发送内容** | 都在应用控制范围之外 |

### 还有几条建议

- **不要多人共用一个 key**
- **新账号前几天少量使用**，别一上来就跑批处理
- **长期固定同一条线路**，不要频繁切换地区
- **遵守所接入服务商的服务条款**

> 本应用**不承诺任何"保证可用"的效果**——这类承诺都不可信。它只是把本地这一侧能查、能调的做到位。

## 常见问题

**Q：必须买吗？**
不用。下载与绝大部分功能都免费；只有内置模板、启用模板开关、指令检测三项采用一次性解锁。自己写的自定义模板可以免费用。

**Q：是订阅吗？会到期吗？**
不是订阅，是**一次性解锁**，不按月收费、不自动续费。

**Q：以后会涨价吗？**
若调整，以应用内实际显示的价格为准；已解锁的用户不受影响（配置在本机，重装应用也不丢）。

**Q：密钥会上传到你的服务器吗？**
不会。密钥只存本机（能用系统密钥库时自动加密），请求直接从你的机器发往模型服务商。

**Q：换电脑要重新买吗？**
激活码绑定设备。换电脑需要在应用里拿到新设备码，联系作者换发激活码。

**Q：更新会丢配置吗？**
不会。对话记录、插件、API 配置都在 `%APPDATA%\葵花宝典`，换 exe 不动它们。

**Q：怎么卸载？**
删掉那个 exe 就完事了（免安装、不写注册表）。要连配置一起清，再删掉 `%APPDATA%\葵花宝典` 目录。

**Q：支持 macOS / Linux 吗？**
目前只发布 Windows x64 版本。

**Q：请求失败怎么办？**
先看「设置 → 环境自检」的结论；再确认密钥是否有效、余额是否充足、该服务商是否需要特定的网络环境。应用会把「模型拒答」「被平台拦截」「网络错误」分类提示，不会让你误判。
